# Studio Pub Boutique

Application web (un seul fichier `index.html`, sans installation) pour créer la publicité d'un produit et la partager sur les réseaux sociaux.

## Ce qu'elle fait
- **Visuel publicitaire** généré automatiquement (photo, nom, prix, promo, bouton d'achat) en 3 formats : carré 1080×1080, story 1080×1920, paysage 1200×630.
- **Texte d'annonce en 14 langues** : français, anglais, arabe, espagnol, portugais, allemand, italien, turc, russe, chinois, hindi, japonais, indonésien, swahili — avec hashtags.
- **Boutons de partage** : Facebook, WhatsApp, X, Telegram, LinkedIn, Threads, Pinterest, Reddit, Bluesky, Tumblr, VK, LINE, Weibo ; et copier-coller guidé pour Instagram, TikTok, Snapchat, YouTube Shorts, Google Business.
- **Suivi** des réseaux où le produit est déjà publié, et brouillon sauvegardé dans le navigateur.
- **Portée mondiale** : liens vers les régies publicitaires (Meta, Google, TikTok, Pinterest, Snapchat, LinkedIn) pour cibler des pays précis.

## Utilisation
Ouvrez `index.html` dans un navigateur, ou hébergez le dossier sur n'importe quel hébergement statique (GitHub Pages, Netlify…).

## Limites
Le nom et la description du produit restent dans la langue où vous les écrivez ; seules les phrases d'accroche sont traduites.
La publication automatique sans clic sur tous les réseaux exige les API officielles de chaque plateforme (comptes professionnels, validation des applis, clés d'accès) : c'est une étape suivante possible.
